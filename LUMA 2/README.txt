LUMA - PHP Website (classroom prototype)

1. Keep the LUMA folder together.
2. Run it through a PHP server (not by double-clicking a PHP file).
   In a terminal inside LUMA, run: php -S localhost:8000
   Then open http://localhost:8000
3. index.php is the homepage. Navigation links connect all six pages.
4. Shared files are inside parts/. Edit header.php once to update all pages.
5. CSS is in css/style.css and uses the original LUMA styleguide colors and fonts.
6. Product data is in data.php. product.php uses $_GET['id'].
7. Product illustrations are placeholders. Cart and checkout are static demos.
   No real payment, account, or order is created. Do not enter real information.
